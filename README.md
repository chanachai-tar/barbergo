# BarberGo — แพลตฟอร์มจองช่างตัดผม (หน้าร้าน + ตัดถึงบ้าน)

ต้นแบบแอปจองคิวช่างตัดผม มี 3 บทบาท: **ลูกค้า**, **ช่างตัดผม** และ **แอดมิน**

## โครงสร้างไฟล์

| ไฟล์ | คืออะไร |
|---|---|
| `index.html` | ต้นแบบหน้าแอป (ไฟล์เดียว เปิดในเบราว์เซอร์ได้เลย) — ข้อมูลยังเก็บในหน่วยความจำ รีเฟรชแล้วหาย |
| `supabase/schema.sql` | ฐานข้อมูลสำหรับ Supabase: ตาราง, สิทธิ์ (RLS), ฟังก์ชันคิดเงิน, ที่เก็บรูป |

## ฟีเจอร์

- **ลูกค้า:** ค้นหา/กรองช่าง, ดูโปรไฟล์และผลงาน, จองคิว (หน้าร้าน/ถึงบ้าน), ติดตามสถานะ, ยกเลิกคิว, แต้มสะสม, รีวิว
- **ช่าง:** รับงานและอัปเดตสถานะ, โปรไฟล์ (รูป, ประสบการณ์, อุปกรณ์, ภาพผลงาน), จัดการบริการและราคา, ส่ง KYC
- **แอดมิน:** อนุมัติ KYC, ตั้งค่าคอมมิชชัน, อัตราค่าเดินทาง, นโยบายยกเลิก

### ค่าเดินทาง (บริการถึงบ้าน)
1. ตอนจอง: ระบบประมาณการจากระยะทาง (กรอกเองหรือใช้ GPS)
2. ตอนช่างรับงาน: ยืนยันยอดจริง — **คำนวณอัตโนมัติ** หรือ **แนบรูปแคปราคาจากแอป Grab** (มีปุ่มอ่านยอดจากรูปอัตโนมัติ)
3. ระบบบวกเข้ายอดรวม และแจ้งส่วนต่างให้ลูกค้าจ่ายเพิ่ม/รับเงินคืน

ค่าเริ่มต้น: ฿40 สำหรับ 2 กม.แรก, ฿12/กม.ถัดไป, คิดไป-กลับ, เพดาน ฿600 (แอดมินปรับได้)

### นโยบายยกเลิก
- ยกเลิกก่อนช่างรับงาน หรือก่อนนัดเกิน 2 ชม. → **คืนเงินเต็มจำนวน**
- ช่างรับงานแล้ว และเหลือไม่ถึง 2 ชม. (ยกเลิกกะทันหัน) → หัก **ค่าเดินทางที่ช่างยืนยัน + ค่ายกเลิก 5% ของค่าบริการ** จ่ายให้ช่าง ที่เหลือคืนลูกค้า
- ช่างยกเลิกเอง → ลูกค้าได้คืนเต็มจำนวนเสมอ

## ติดตั้งฐานข้อมูล (Supabase)

1. สร้างโปรเจกต์ที่ [supabase.com](https://supabase.com) (เลือก region Singapore ใกล้ไทยที่สุด)
2. ไปที่ **SQL Editor** → วางไฟล์ `supabase/schema.sql` ทั้งไฟล์ → **Run**
3. สมัครบัญชีของคุณผ่านแอป แล้วตั้งตัวเองเป็นแอดมิน:
   ```sql
   update public.profiles set role = 'admin' where id = '<your-user-uuid>';
   ```

### หลักความปลอดภัยของฐานข้อมูล
- ยอดเงินทุกอย่าง (ค่าบริการ, ค่าเดินทาง, ค่ายกเลิก, คืนเงิน) **คำนวณบนเซิร์ฟเวอร์** ผ่านฟังก์ชัน `create_booking`, `accept_order`, `advance_order`, `cancel_order` — ลูกค้า/ช่างแก้ตัวเลขเงินในตารางเองไม่ได้
- ช่างอนุมัติ KYC ตัวเองไม่ได้ ลูกค้าเพิ่มแต้มตัวเองไม่ได้ (กำหนดสิทธิ์ระดับคอลัมน์)
- รูปแคปค่าเดินทางและเอกสาร KYC อยู่ใน bucket แบบ private
- `paid_amount` / `refund_amount` ต้องเชื่อมกับ webhook ของผู้ให้บริการชำระเงิน (ยังไม่ได้ทำ)

## ยังต้องทำก่อนใช้งานจริง
- [ ] เชื่อม `index.html` กับ Supabase (ล็อกอิน OTP, ดึง/บันทึกข้อมูลจริง, อัปโหลดรูป)
- [ ] ระบบชำระเงินจริง (PromptPay/บัตร) + webhook อัปเดตยอดที่จ่ายและคืนเงิน
- [ ] แจ้งเตือน (LINE / Push) เมื่อมีคิวใหม่ ช่างรับงาน หรือมีการยกเลิก
- [ ] นโยบายความเป็นส่วนตัว (PDPA) และข้อตกลงการใช้งาน
